## Environment variables

- `.env.local` — your local working copy; **not** committed (`.gitignore`d)

Fill in real values in `.env.local` before deploying.

### Resend

Transactional email for the contact form goes through Resend, sending from `hello@waylandandco.com`. On submission, two emails are queued: a lead notification to `hello@waylandandco.com` and an auto-reply to the prospect.

**To verify Resend setup:**

1. Confirm the sending domain for `hello@waylandandco.com` is verified at <https://resend.com/domains>. **Resend rejects sends from unverified domains** — this is the most common cause of silent send failures.
2. Create an API key at <https://resend.com/api-keys> with `Sending access` scope.
3. Verify the env vars in `.env.local`:
   - `RESEND_API_KEY`
   - `RESEND_FROM`
4. Submit the contact form and confirm both the lead notification and the auto-reply arrive. The form returns success based on the HubSpot submission; Resend failures are logged server-side only.

> **Fire-and-forget by design:** the contact form responds to the user as soon as HubSpot accepts the submission. Resend sends run via `after()` from `next/server` after the response — failures surface in server logs, never in the user-facing UI.

### Plausible

This site loads the Plausible analytics script with `data-domain="waylandandco.com"`. The script is loaded only when `NEXT_PUBLIC_PLAUSIBLE_DOMAIN` is set; if unset, no script tag renders.

**To verify Plausible setup:**

1. Confirm the site `waylandandco.com` exists at <https://plausible.io/sites>. Plausible only records events for domains registered to your account.
2. Verify the env var in `.env.local`:
   - `NEXT_PUBLIC_PLAUSIBLE_DOMAIN`
3. Load the site in a browser with adblockers disabled, then confirm the page appears on the Plausible dashboard within ~30 seconds.
4. From the command line, `curl -s http://localhost:3000 | grep plausible.io` should return the script tag with `data-domain="waylandandco.com"`.

> **Adblockers will block Plausible.** Treat Plausible as a directional tool, not a source of truth for traffic. Server-side request logs are the authoritative count.
